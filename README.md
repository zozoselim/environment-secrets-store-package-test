# Environment Secrets Store Package

NovaVision workflow sistemi için Environment Secrets Store bileşeninin
başlangıç package yapısıdır.

Bu bileşen, environment variable olarak saklanan API anahtarı, token ve parola
gibi hassas değerlerin çalışma anında okunmasını ve diğer workflow
bileşenlerine aktarılmasını sağlayacaktır.

- NovaVision package template reviewed
