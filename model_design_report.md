# Environment Secrets Store Model Design Report

## Purpose

The PackageModel structure was redesigned for the Environment Secrets Store
component.

## Configuration

The component accepts the following configuration:

```text
variables_storing_secrets: List[str]
```

This configuration contains the names of environment variables that store
secret values.

## Validation Rules

- The list must contain at least one variable name.
- Variable names cannot be empty.
- Variable names must use a valid environment variable format.
- Output names are generated by converting variable names to lowercase.
- Conflicting output names are rejected.

## Input Structure

The component does not require an input from another workflow component.

## Output Structure

Outputs are generated dynamically according to the requested environment
variable names.

Example:

```text
OPENAI_API_KEY → openai_api_key
DATABASE_PASSWORD → database_password
```
